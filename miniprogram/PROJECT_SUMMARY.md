## 🔧 配置步骤

### 步骤1: 准备图标（必需）
```bash
# 方式A: 使用ImageMagick生成纯色图标
cd /home/gao/pro/miniprogram/images
convert -size 81x81 xc:'#8a8a8a' monitor.png
convert -size 81x81 xc:'#00d4ff' monitor-active.png
convert -size 81x81 xc:'#8a8a8a' history.png
convert -size 81x81 xc:'#00d4ff' history-active.png

# 方式B: 从iconfont.cn下载专业图标
```

### 步骤2: 配置后端
```javascript
// 编辑 miniprogram/app.js
globalData: {
  baseUrl: 'https://your-domain.com',  // 修改此处
  // ...
}
```

### 步骤3: 导入测试
1. 打开微信开发者工具
2. 导入项目目录: `/home/gao/pro/miniprogram`
3. 使用测试AppID
4. 点击编译运行

### 步骤4: 启动后端
```bash
cd /home/gao/pro
python app.py  # 或 gunicorn app:app --bind 0.0.0.0:4000
```

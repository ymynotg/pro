# 套利小韭

一个简洁的自选基金监控工具，专注于核心功能。

## 功能特性

### 核心功能
- ✅ **自选基金管理** - 添加、删除自选基金
- ✅ **实时数据更新** - 自动从API获取最新数据
- ✅ **搜索过滤** - 快速搜索基金代码或名称
- ✅ **表格排序** - 点击表头进行升序/降序排序
- ✅ **公告列** - 显示基金相关公告信息

### 数据展示
- 代码、名称、当前价、涨跌幅
- 净值、溢价率、估值、估溢率
- 申购/限额、赎回状态
- 公告信息

### 技术特点
- 纯前端实现，无需后端支持
- 使用localStorage持久化存储
- 响应式设计，支持移动端
- 自动刷新数据（每5分钟）

## 使用方法

### 1. 添加基金
点击"+ 增加"按钮，输入基金代码（如：160416），系统会自动从API获取数据。

### 2. 删除基金
点击对应行的"删除"按钮，确认后即可删除。

### 3. 搜索基金
在搜索框输入代码或名称，表格会实时过滤显示匹配结果。

### 4. 排序数据
点击表头可以进行升序或降序排序。

### 5. 查看历史
点击基金代码可以查看历史数据（需要history.html支持）。

## 数据来源

数据来自后端API接口：
- `/api/lof` - LOF基金数据
- `/api/qdii` - QDII基金数据

## 本地存储

数据保存在浏览器的localStorage中：
- 存储键：`xiaojiu_favorites`
- 刷新页面数据不丢失
- 清除浏览器数据会删除自选列表

## 注意事项

1. 需要后端API支持才能获取实时数据
2. 公告信息需要手动维护
3. 数据仅供参考，不构成投资建议
